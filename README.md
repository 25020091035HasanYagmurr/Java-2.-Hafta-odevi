# Java OOP Projeleri ☕

Bu depo, Nesne Yönelimli Programlama (OOP) konseptlerini pekiştirmek amacıyla geliştirilen çeşitli Java projelerini içermektedir. Projelerin tamamı NetBeans IDE kullanılarak oluşturulmuştur.

## 🚀 İçerik
Depo içerisinde 11 farklı Java projesi bulunmaktadır. Çalışmalar genel olarak şu konuları kapsamaktadır:
- Sınıf (Class) ve Nesne (Object) mimarisi
- Kapsülleme (Encapsulation - Getter/Setter kullanımı)
- Kurucu Metotlar (Constructors)
- UML diyagramlarını koda dönüştürme (Fan, RegularPolygon vb. modellemeler)

## 🛠️ Kullanılan Teknolojiler
- **Dil:** Java
- **Geliştirme Ortamı:** NetBeans IDE

## 📂 Kurulum ve Çalıştırma
Projeler tam NetBeans dizin yapısıyla (src, nbproject) yüklenmiştir. Kodları çalıştırmak için repo'yu klonlayıp veya indirip NetBeans üzerinden doğrudan açabilirsiniz (`File > Open Project`).
